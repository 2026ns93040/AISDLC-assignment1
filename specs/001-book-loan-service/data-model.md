# Data Model: Library Book-Loan Service

## Book

Represents a catalog item.

| Field | Type/constraint | Notes |
|---|---|---|
| `id` | Unique identifier | Generated by the service |
| `title` | Non-empty text | Required |
| `author` | Text | Required by the create contract |
| `isbn` | Exactly 13 digits, unique | Checksum validation is out of scope |
| `total_copies` | Integer >= 1 | Total owned copies |

`available_copies` is a derived response field:
`total_copies - count(active loans for the book)`.

## Member

Represents a borrower.

| Field | Type/constraint | Notes |
|---|---|---|
| `id` | Unique identifier | Generated by the service |
| `name` | Non-empty text | Required |
| `email` | Valid email format, unique case-insensitively | Required |

## Loan

Represents one borrowing event.

| Field | Type/constraint | Notes |
|---|---|---|
| `id` | Unique identifier | Generated by the service |
| `book_id` | Existing Book reference | Required |
| `member_id` | Existing Member reference | Required |
| `loaned_at` | UTC timestamp | Set on successful creation |
| `due_date` | UTC calendar date | `loaned_at` date plus 14 days |
| `returned_at` | Nullable UTC timestamp | Unset while active |

## Relationships and invariants

- One Book has many Loans.
- One Member has many Loans.
- A Loan references exactly one Book and one Member.
- A loan is active when `returned_at` is unset.
- Active loans for a Book MUST NOT exceed `total_copies`.
- Active loans for a Member MUST NOT exceed 3.
- Returning a loan sets `returned_at` once; a second return is rejected.
- Books, Members, and Loans persist in the runtime SQLite database.
